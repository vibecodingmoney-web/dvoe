# Двое — Telegram Mini App для пар ❤️

Маленький тёплый мир для двоих: счётчик дней вместе, **календарь памятных дат с шаблонами**, **общий питомец-тамагочи**, кнопка «Думаю о тебе» (100+ фраз, раз в 3 часа), автоматические напоминания и итоги недели.

**Стек:** Node.js + Express + grammY (бот) · Postgres (Neon) · фронтенд на чистом HTML/CSS/JS без сборки · хостинг Render (free) + UptimeRobot.

---

## Как это работает

1. **Участник А** открывает бота → вводит *имя, пол, возраст, дату начала отношений* и (по желанию) *дату свадьбы* → получает ссылку-приглашение.
2. **Участник Б** открывает ссылку → вводит *имя, пол и возраст* → пара готова.
3. Дальше всё само: бот напоминает о датах, поздравляет с «красивыми» числами (100, 200, 500 дней, месяцы, годы…), заботится о питомце и присылает итоги недели.

Если вы уже пользовались приложением раньше, при следующем входе оно попросит один раз указать пол и возраст.

Приложение рассчитано на **много пар**: у каждой пары свои данные, доступ проверяется на сервере по подписи Telegram (`initData`).

**Время.** Часовой пояс у пользователей не спрашивается. Всё считается по одному поясу сервера — `APP_TZ` (по умолчанию `Europe/Kyiv`). Вопрос дня приходит в 10:00 по этому поясу.

## Запуск шаг за шагом (первый раз)

### 1. Создай бота
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и username (например `dvoe_love_bot`).
2. Сохрани **токен** (вида `123456:ABC...`). Никому не показывай и не коммить в git. Если токен утёк — `/revoke` в BotFather.

### 2. Создай базу данных (бесплатно)
Бесплатный Postgres на Render удаляется через 30 дней, поэтому берём **Neon** (или Supabase).
1. Зарегистрируйся на [neon.tech](https://neon.tech) → *Create project*.
2. Скопируй **Connection string** (начинается с `postgresql://`, внутри есть `sslmode=require`) — это `DATABASE_URL`.
3. Таблицы создавать не нужно — приложение создаёт их само при первом запуске.

### 3. Выложи код на GitHub
```bash
cd dvoe
npm install            # создаст package-lock.json — закоммить его тоже
git init && git add . && git commit -m "Двое"
# создай пустой репозиторий на github.com и:
git remote add origin https://github.com/ТВОЙ_НИК/dvoe.git
git push -u origin main
```
Файл `.env` в git не попадает (он в `.gitignore`).

### 4. Задеплой на Render
1. [render.com](https://render.com) → **New → Web Service** → подключи репозиторий.
2. Настройки:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
   - **Advanced → Health Check Path:** `/health`
3. **Environment Variables:**

   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | токен от BotFather |
   | `DATABASE_URL` | строка подключения из Neon |
   | `ADMIN_IDS` | твой Telegram id (для админ-режима) |
   | `CRON_KEY` | любая длинная случайная строка (для внешнего «тика», см. ниже) |
   | `APP_TZ` | `Europe/Kyiv` (или твой пояс) |

   `PUBLIC_URL` указывать не нужно: Render сам передаёт `RENDER_EXTERNAL_URL`, и сервер при старте сам ставит вебхук и кнопку меню бота.
4. Нажми **Create Web Service**. В логах должны появиться строки `🤖 Бот: @...`, `🔗 Вебхук: ...`, `🚀 Сервер слушает порт`.

> Вместо ручной настройки можно использовать `render.yaml` (Blueprint): **New → Blueprint**.

### 5. Не дай сервису заснуть (UptimeRobot)
Бесплатный сервис Render засыпает через 15 минут без запросов; после сна первый запрос идёт 30–60 секунд, а уведомления в это время не отправляются.
1. [uptimerobot.com](https://uptimerobot.com) → **Add New Monitor** → тип **HTTP(s)**.
2. URL: `https://ИМЯ.onrender.com/health`, интервал **5 минут**.

Необязательно, но надёжнее: второй монитор на `https://ИМЯ.onrender.com/cron/tick?key=ТВОЙ_CRON_KEY` — он запускает планировщик извне. Повторные вызовы безопасны: каждое уведомление отправляется строго один раз.

### 6. (Необязательно) Прямая ссылка на Mini App
Без этого шага всё работает: приглашение идёт через бота (`t.me/бот?start=pair_...`), а в боте есть кнопка меню «Открыть ❤️».
Чтобы ссылка открывала приложение сразу: BotFather → `/newapp` → выбери бота → URL приложения = адрес на Render → короткое имя, например `app`. Потом добавь в Render переменную `MINIAPP_LINK=https://t.me/ИМЯ_БОТА/app`.

### 7. Проверка
1. Напиши боту `/start` → нажми «Открыть».
2. Создай пару (имя + дата), нажми «Отправить приглашение» и открой ссылку со второго аккаунта.
3. На втором аккаунте введи имя → на главной нажми сердечко: первому придёт сообщение от бота.

## Админ-режим
Укажи свой Telegram id в переменной `ADMIN_IDS` (узнать: написать боту `/id` или @userinfobot; несколько админов — через запятую). Тогда в приложении появится кнопка **«⚙️ Админ-режим» / «👤 Обычный режим»** — только у тебя. В админ-режиме: сводная статистика и **все пары** (имена, id, статус, дни вместе, активность, уведомления). Личные тексты пар админу не показываются. Доступ проверяется на сервере по подписанному id, а не только скрытием кнопки.

## Что внутри

| Функция | Как работает |
|---|---|
| Счётчик дней | Дни, а также «N лет M месяцев K дней», считаются от даты начала |
| Годовщины | Автоматически: месяц, 3/6/9 месяцев, годы, 100/111/200/222/…/1000/… дней. Пуш за 7 дней, за день и в сам день |
| Календарь | Месячная сетка. События создаёт любой из двоих: разовые или «каждый год». **Шаблоны**: первое свидание, первый поцелуй, первая встреча, первое «люблю», первая поездка, жизнь вместе, знакомство с родителями, предложение, дни рождения и «своя дата». Авто-даты (начало, красивые числа дней, годовщины) и свадьба с названиями (ситцевая, бумажная…) добавляются сами. Напоминание за день и в сам день |
| Свадьба | Необязательная дата при регистрации (меняется на вкладке «Мы»). Счётчик «до свадьбы» / «в браке», годовщины |
| Питомец | Один на пару: котик, зайка, мишка или щенок. Начинает яйцом, которое надо согреть вместе → малыш → подросток → взрослый. Кормить (4 вида еды), играть, обнимать. Сытость и настроение медленно падают, но питомец **никогда не умирает** — только грустит. Если за день позаботились оба — бонус любви |
| Думаю о тебе | Человек сам вписывает текст (до 500 символов) и нажимает сердечко — партнёру приходит сообщение «Думаю о тебе» с этим текстом. Кулдаун **3 часа** (меняется в `THOUGHT_COOLDOWN_MIN`) |
| Бот сам | Поздравления с красивыми датами · напоминания о ваших событиях · «питомец скучает» · напоминание автору о неприглашённом партнёре · «давно не виделись» после 3 дней тишины · итоги недели в воскресенье вечером |

Тихие часы соблюдаются: уведомления не приходят ночью.

## Свои тексты
- Фразы «Думаю о тебе» — в `src/content.js`. Пиши без «рад/рада», «скучал/скучала» — тест `npm test` это проверяет.
- Шаблоны памятных дат — `public/templates.js` (допиши строку — шаблон появится в календаре).
- Питомцы (названия, еда, скорость роста) — `src/pet-core.js`, их рисунки — `public/pet-art.js`.
- Цвета и шрифты — переменные в начале `public/style.css`.

## Локальная разработка
```bash
cp .env.example .env   # впиши BOT_TOKEN и DATABASE_URL
npm run dev
```
Без `PUBLIC_URL` бот работает через long polling. Кнопки `web_app` в Telegram требуют https-адрес, поэтому для проверки внутри Telegram нужен туннель (например, `cloudflared tunnel`) — его адрес пропиши в `PUBLIC_URL`.

Посмотреть интерфейс в обычном браузере можно без Telegram: в `.env` поставь `DEV_AUTH=1` и открой `http://localhost:3000/?dev=1:Anya` (`1` — любой id, дальше имя **латиницей**; для второго участника — другой id, например `?dev=2:Max&invite=КОД`).

```bash
npm test               # тесты подписи Telegram, дат, годовщин и текстов
```

## Если что-то не так
- **Бот не отвечает** — проверь логи Render: есть ли `🔗 Вебхук`. Верен ли `BOT_TOKEN`?
- **`Не заданы переменные окружения`** — добавь `BOT_TOKEN` и `DATABASE_URL` в Render → Environment.
- **Ошибка базы** — в `DATABASE_URL` должна быть строка из Neon целиком, с `sslmode=require`.
- **Уведомления не приходят** — человек должен хотя бы раз нажать `/start` у бота или разрешить боту писать (в приложении появится плашка «Разрешить»).
- **Долго открывается** — сервис заснул; проверь, что монитор UptimeRobot активен.

## Безопасность
- Каждый запрос подписан Telegram; сервер проверяет подпись (HMAC) и срок действия.
- Пользователь видит только данные своей пары.
- Секреты — только в переменных окружения.

## Обновление с прежней версии
База обновляется сама при запуске (добавляются новые колонки и таблицы, данные пар сохраняются). Старая таблица `answers` (ответы на вопросы) больше не используется — при желании удали её в Neon → SQL Editor: `DROP TABLE answers;`.
